Gerenciamento de Tarefas e Projetos com Vue.js 3

O projeto

Sistema de cadastro, listagem, detalhamento e edição de projetos e tarefas, construído como uma SPA (Single Page Application) com Vue.js 3.

Stack usada no projeto

Vue 3 Composition API + <script setup> TypeScript Vue Router Vite json-server (API local)

Vue.js 3 no código do projeto

Inicialização da aplicação

// src/main.ts
import { createApp } from 'vue'
import App from './App.vue'
import router from './router'

createApp(App).use(router).mount('#app')

Single File Components (.vue)

Cada tela é um arquivo .vue com <script setup lang="ts">, <template> e <style scoped>.

Composition API e reatividade

  • ref, computed, onMounted, watch — usados em ListaTarefas.vue e FormularioTarefa.vue
  • defineProps — recebe dados do pai (inicial, modo, enviando)
  • defineEmits — avisa o pai quando o formulário é enviado
  • v-model — binding bidirecional nos campos do formulário
  • v-for — renderiza a lista de cards em ListaTarefas.vue

Navegação no projeto com Vue Router

Todas as rotas da SPA

// src/router.ts
const router = createRouter({
  history: createWebHistory(),
  routes: [
    { path: '/', component: ListaTarefas, meta: { titulo: 'Tarefas' } },
    { path: '/projetos', component: ListaProjetos },
    { path: '/tarefas/nova', component: NovaTarefa },
    { path: '/tarefas/:id', component: DetalheTarefa },
    { path: '/tarefas/:id/editar', component: EditarTarefa },
    { path: '/projetos/:id', component: DetalhesProjeto },
    { path: '/projetos/:id/editar', component: EditarProjeto },
    { path: '/:pathMatch(.*)*', component: PlaceholderView },
  ],
})
  • Rotas estáticas: /, /projetos, /tarefas/nova
  • Rotas dinâmicas com parâmetros: /tarefas/:id, /projetos/:id/editar
  • Meta de rota: meta: { titulo: '...' } define o título de cada página
  • Rota curinga: /:pathMatch(.*)* redireciona para a página não encontrada

Relação com o projeto: o Vue Router gerencia a navegação entre tarefas e projetos sem recarregar a página.

API, acessibilidade e ferramentas oficiais do Vue

Integração com API

// src/api.ts
export function listarTarefas(): Promise {
  return requisicao('/tarefas')
}

export function criarTarefa(tarefa: NovaTarefa): Promise {
  return requisicao('/tarefas', { method: 'POST', body: tarefa })
}

export function buscarProjetoComTarefas(id: string) {
  return requisicao(`/projetos/${id}?_embed=tarefas`)
}

json-server simula a API REST localmente na porta 3000 (npm run api).

Acessibilidade no FormularioTarefa.vue

  • aria-invalid, aria-describedby, role="alert", role="status"
  • Foco dirigido com nextTick (resumo de erros e aviso de envio)
  • Navegação exclusivamente por teclado nos controles nativos
